# Demos

All media is generated by [`demo/capture.mjs`](https://github.com/zviryatko/drupal-react-scaffold-theme/blob/main/demo/capture.mjs)
(Playwright). The DevTools pane is the real Chromium DevTools, Network tab filtered by Fetch/XHR.

## Recipe explorer with DevTools

Search, difficulty, category and preparation time filters, sorting and pager. Every change is one `fetch` to `/api/recipes`
(a `views_better_rest` display). The state is mirrored in the URL.

<Video src="/media/recipe-explorer-demo.mp4" poster="/media/screenshots/09-recipe-explorer-devtools.png" />

## Node list: table, filter and "Edit in Modal"

The table is a React component, the "Edit in Modal" link is plain Drupal ajax (`use-ajax`) inside the React markup. DevTools shows the
`node?...` fetches and the `edit?_wrapper_format=drupal_modal` XHR.

<Video src="/media/node-list-modal-demo.mp4" poster="/media/screenshots/10-node-list-modal-devtools.png" />

## Regenerate

The recorder is in the repository only (`demo/` is not part of release archives). With a git checkout of the base theme, the example subtheme built and enabled on a site that has the `demo_umami` content (see [Getting started](/guide/getting-started#try-the-example-subtheme)):

```bash
cd react_scaffold/demo
npm install
npx playwright install chromium
BASE_URL=https://your-site.example npm run capture
# or from the base theme folder: BASE_URL=... npm run demo
```

Needs `ffmpeg`. The modal demo logs in as `admin` / `admin`, so create that user on your demo site. Output goes to `docs/public/media`.
