# Gallery

The page builder, feature by feature. Click a picture for the full size. The screenshots are from the example
subtheme (`react_scaffold_demo`) on the Umami demo content; the page was composed by the
[AI assistant](/builder/ai) and then changed by hand, as in the video.

<Video src="/media/page-builder-ai.mp4" poster="/media/builder/ai-assistant.png" />

<div class="shots">

## A component

<div class="shots">
<Shot src="/media/builder/component-fields.png" title="Fields from the component's props">Each prop of the <code>*.component.yml</code> is a field, with its description as help. <a href="./components">Components</a></Shot>
<Shot src="/media/builder/tokens.png" title="Tokens">Typing <code>[</code> in a text field suggests Drupal tokens of the page.</Shot>
<Shot src="/media/builder/media-library.png" title="Media library">Images and backgrounds are picked from Drupal's media library, with an image style or a responsive image style.</Shot>
<Shot src="/media/builder/layout-and-style.png" title="Layout and style">Spacing, alignment and text for every component, from the scales the theme declares. <a href="./styling">Tokens, features and styling</a></Shot>
<Shot src="/media/builder/background.png" title="Background">A colour of the theme's palette, or an image. There is no free colour.</Shot>
<Shot src="/media/builder/library.png" title="Library">Save a block and use it on other pages, linked or as a copy. <a href="./library">Library of saved blocks</a></Shot>
</div>
